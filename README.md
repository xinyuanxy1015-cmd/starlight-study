# KK的星空学习册

适合小学孩子在 iPad 上阅读的天文学习材料，包含 576 道原题、11 个主题、81 个小单元。

先读单元导读，再逐题学习。题干、选项、原题号与原答案保留原素材，答案用黄色高亮；新增的一句话小解释后附水彩知识图示，可点开放大。同一知识点共用图示，共 197 张。对旧说法、歧义及错误答案的说明单独列在题下。

点“我读懂了”才点亮星星，翻页不会自动打卡。无需登录，进度保存在当前设备，建议定期在“使用与备份”导出记录。

## 在 iPad 上使用

1. 在 Safari 打开 [KK的星空学习册](https://xinyuanxy1015-cmd.github.io/starlight-study/)。
2. 首次保持联网，等“使用与备份”显示离线内容已准备好。
3. 在 Safari 的“分享”菜单选择“添加到主屏幕”，此后可从图标进入。
4. 更新后如看到“更新学习册”，点一下即可使用新内容。原网址及本机进度保持不变。

同学可使用同一网址，各自设备分别保存进度。清理网站数据会影响本机记录，可用导出的备份恢复。
